# 計畫：README 改寫（以想安裝來用的玩家為主）

狀態：2026-11-12 核准。只改文件，不動程式；沒有使用者的指示不 commit、不推送。

## 背景

README 是一路隨各階段加內容長出來的（英文 291 行、中文 247 行）。對玩家來說有三個問題：

- 開頭和「可以問什麼」還停在 0.8 的說法（例如「裝備之後的版本才加入」已過時）。
- 0.9～0.10 最重要的 PoB 匯出，只散落在工具表的一格和「限制」的四大段裡，沒有一節告訴玩家
  「匯入碼裡有什麼、哪些是假設、怎麼貼、怎麼看」。
- 資料來源表、更新範圍表、蒐集指令、開發說明這些開發者內容占了一半篇幅，玩家要找的東西被淹沒。

你在 2026-11-12 的決定：由我改寫、你審；主要讀者是想安裝來用的玩家；細節審稿時再討論。

## 驗收

1. 玩家從 README 開頭讀到「匯入 Path of Building」就能完成：安裝、提問、貼匯入碼、知道哪些數字是假設。
2. 原 README 的每一項事實都還找得到（在 README 或兩份新文件中），沒有內容遺失；我會列出搬移對照給你審。
3. 兩份 README 結構與內容一致；文中的數字（工具數、請求數、筆數、版本）與目前程式一致。
4. 測試全過、plugin 嚴格驗證通過。
5. 你審稿確認後才 commit。
