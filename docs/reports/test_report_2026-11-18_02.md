Found and fixed during the run: the first version of the requirement lines covered only the class's own
bases, so `敏捷$` still matched a Dexterity requirement on a strength-only class (3 pieces); one line per
attribute was added. A thousands rule that read `Level 5, 12 Dex` as one number was narrowed to three-digit
groups, and a sign that applied to only one branch of the number pattern was fixed; both caught before tests.
